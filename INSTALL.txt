REWIRE — 28 DAY RESET (PWA UPDATE)

1. Extract this ZIP on your phone.
2. In your GitHub repository, upload/replace these files at the repository ROOT (not inside a subfolder): index.html, manifest.json, service-worker.js, INSTALL.txt.
3. Upload/replace icons/icon-192.png and icons/icon-512.png inside an icons folder.
4. Commit the upload. Wait for GitHub Pages deployment (usually 1–3 minutes).
5. Open https://milanmishra-create.github.io/rewire-app/ in Chrome.
6. Chrome menu (⋮) > Install app. If Install app is unavailable, use Add to Home screen.

The manifest has been validated as JSON. The app uses local browser storage for journal/progress. Export a backup from My progress regularly. Do not clear site data if you want to keep saved entries.
